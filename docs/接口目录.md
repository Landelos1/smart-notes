## 阅读约定

- 基础地址：本机后端 http://localhost:8889；浏览器开发时通过 http://localhost:3000 的 /api 代理访问。
- 路径中的 {id} 等应替换为真实 ID；共享知识库路径的 knowledgeBaseId 受后端数字正则限制，表内省略正则。
- 默认需要 Authorization: Bearer <token> 请求头（当前后端 token-name=Authorization、token-prefix=Bearer）。前端本地存储键仍为 satoken。标注 @SaIgnore 表示代码跳过统一登录拦截，不保证业务服务不再校验。标注 ADMIN 的还需系统管理员角色；所属人、团队和知识库权限仍由业务服务决定。
- 参数声明保留当前 Java 签名：@PathVariable 是路径参数；@RequestParam 是查询参数（MultipartFile 的 file 是 multipart 字段）；@RequestBody 是 JSON；未标注的 GET 查询 DTO 按字段绑定查询参数。
- @RequestParam 默认 required=true；required=false 是可选，defaultValue 是省略时的值。DTO 字段和声明校验见字段字典；是否执行 Bean Validation 取决于端点 @Valid/@Validated 和实际服务校验。
- HttpServletRequest/HttpServletResponse 是服务器对象，不是前端要传的字段。没有参数声明的接口不需要 JSON 请求体。
- Result<T> 表示外层 {code,message,data}，T 是 data 的类型；PageResult<T> 是 {data:[...],total}。Flux<String> 是 SSE 文本流；void 下载和支付宝通知的 String 不按普通 JSON 处理。
- 错误码、SSE 解码、上传状态、动态 Map 响应和已知缺陷参阅交接与联调指南。本文源码行号为生成当日位置，后续改动可能移动。
