# 学习闭环功能前后端联调报告

日期：2026-11-15
覆盖：Agent 个人业务上下文、笔记自动生成学习安排、任务与复习计划管理。

## 实现与修复

- Agent 对话按登录用户读取个人笔记、任务、复习计划和知识库片段。受控工具通过 `POST /api/agent/tools/execute` 执行；用户 ID 从登录态取得，工具写入时校验关联笔记归属。
- 笔记页提供“学习安排”入口。后端调用实际聊天模型，最多生成 5 个任务和 2 个复习计划，保存时标记 `note-ai`；再次生成只替换同一笔记的 AI 生成记录。
- 用户端“任务与复习”页支持手动创建、完成/恢复和删除。修复确认框参数、业务错误展示、重复提交保护和移动端窄屏溢出。
- 修复任务恢复后 `completed_time` 未清空、可选字段更新与数据库落值不一致的问题；任务和复习计划标题在服务层校验，覆盖 Agent 工具调用路径。错误响应码不再使用业务成功码 `0`。

## 联调环境与范围

在本地运行的 Spring Boot、Vite、PostgreSQL 16 + pgvector、Redis 7、聊天模型、百炼 Embedding 和 OSS 配置上实测。接口请求通过用户端本地 `/api` 代理访问；模型回答及文件检索均使用实际服务，不以模拟响应代替。

这轮验证针对学习闭环，不代表所有管理端、支付、团队并发、文件格式或生产部署流程已完成验收。聊天 Agent 自动读取上下文；需要写入业务数据时仍须调用受控工具接口，当前聊天界面不会根据自然语言自动执行写操作。回收站彻底删除目前移除数据库记录和向量，不会自动删除云端 OSS 原对象。

## 测试数据清理

已按本轮唯一标识清理测试任务、复习计划、笔记、笔记本、Agent 会话、知识库文件记录及对应向量，并移除隔离验证账号。没有删除既有用户或其原始笔记。

OSS 存储服务当前的回收站删除流程不会物理删除对象；本轮上传的唯一 TXT 测试对象 `向量索引学习资料-星桥-1794705051263.txt` 仍留在原 OSS Bucket 中。由于数据库文件记录已清理，它不会出现在应用文件列表或知识库检索中；如需释放该对象占用的云存储，可在 OSS 控制台按文件名查找并删除。

## 追加：复习计划与任务页面回归

- 复习频率可选每天、每周指定星期或每隔 1-365 天；计划表展示来源类型、来源笔记、接下来 3 次日期，展开后可查看接下来 5 次日期。编辑时可以调整周期、日期范围、目标和笔记关联。
- 学习任务支持按关联笔记本分类、按优先级升序/降序排序；分类排序时会补查较早的来源笔记，并在每项任务上显示笔记本名称。
- 笔记页 AI 生成的计划及任务显示来源笔记链接；手动计划可关联笔记，也可保持独立。点击链接会打开应用内对应笔记。
- 任务创建和更新 DTO 改用 ISO `LocalDateTime` 解析，修复截止时间含毫秒/微秒时点击圆圈完成或恢复失败的问题。
- 本机 PostgreSQL 执行 `20261115_review_plan_recurrence.sql` 成功，并验证重复执行安全。通过登录用户的真实 API 创建、完成、恢复并删除带 6 位小数秒截止时间的任务；创建每天、指定星期、自定义间隔计划，刷新列表验证持久化，编辑间隔并清除笔记关联。测试记录已清理，数据库核对为 0 条残留。
- 本轮完成后端 Maven 打包、用户端 `npm test`（10 项通过，含纽约时区夏令时边界）、`npm run build`。用户端 Vite 服务返回 HTTP 200；本轮业务交互通过后端 API 验证。

已有数据库部署时需先执行 `initialization-note-side/deploy/migrations/20261115_review_plan_recurrence.sql`，然后重启后端以加载新代码；空库直接使用更新后的 `init-local.sql`。
