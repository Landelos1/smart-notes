## 使用规则

- DTO 多用于请求，VO 多用于响应；实际入口和 HTTP 参数位置以接口目录为准，不能把整个 DTO 都当作查询参数或都当作 body。
- 字段名称是当前 Java 属性名称；若有 Jackson 注解，以注解为准。@JsonIgnore 字段不进入 JSON，表中保留只是说明源模型，不能据此传入或期待返回。
- 类型转换：String→字符串，Boolean/boolean→布尔值，Integer/Long/int/long/Double→数值，BigDecimal→金额数值，List/数组→数组，Map→对象。不要把 Java 泛型名称直接发给后端。
- Long 当前没有统一序列化为字符串的配置。前端不要对较长 ID 进行计算或无意转 Number；超过 JS 安全整数范围须与后端统一精度方案，转字符串也无法挽救已经丢失的精度。
- LocalDateTime 默认采用 ISO 日期时间字符串，例如 2026-10-28T10:30:00；部分字段带 @JsonFormat，Date 与 LocalDateTime 的格式不可混为一谈，见对应注解和真实返回。
- 默认值栏是字段初始化值，不代表服务端最终默认值；“未初始化”表示 Java 声明未赋值，引用类型通常为 null。注解是声明约束，不保证所有端点都启用 @Valid。
- 注释来自当前源码，可能有遗留描述。用户 roleType 应按 RoleType 枚举解释：1=USER，2=ADMIN；不能沿用旧的求职者/招聘者/3=管理员注释。注册权限由服务端控制，界面不能据此开放自助创建管理员。
- 团队嵌套类按完整名称列出；TeamDTO、TeamVO 是容器类，不是需要在 JSON 外再包一层的字段。
- UserAISettings 的 API Key 字段是敏感信息，应在 UI 中掩码，不用于演示数据、截图或日志。
