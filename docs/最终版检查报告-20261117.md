# 最终版检查报告

检查日期：2026-11-17。范围包含 Java 后端、当前新版用户端 `note-vue`、管理端 `art-design-pro`、数据库数据与提交配置。

**结论：已确认的高影响权限问题均已修复，新增隔离回归通过，修复版后端已在本机 8889 启动并通过只读套餐接口检查。** 本报告没有把构建成功等同于全部业务通过，也没有执行真实付款或跨账号在线 API 验证。

## 修复内容

### 账号与访问控制

- 个人资料接口改用白名单 DTO，账号 ID 取登录态。请求中的角色、状态、密码、认证字段和其他用户 ID 不再进入更新列，修复普通用户自提管理员的问题。
- 生日使用 `yyyy-MM-dd`；省略保留原值，显式 `null` 清空，修复前端清空后无法持久化的情况。
- 增加个人改密接口，验证原密码后保存哈希并注销所有登录会话。管理员修改角色、状态或密码，以及禁用、删除账号时也注销会话。
- 空列表批量禁用直接返回，防止误形成无条件更新；注册与后台账号表单补齐密码、角色、状态和性别校验。
- 五个看板接口、向量库诊断和三个遗留调试接口限制为管理员。三个调试入口为 `/api/chat/stream/local`、`/api/documents/test-vector`、`/api/documents/test-parse`；普通聊天、上传和知识库使用原业务入口。
- 订单详情接口仅允许订单本人或管理员读取；不存在和无权访问的订单使用同一错误响应。支付宝同步回调不再输出订单 JSON，只重定向至用户端支付结果页；页面用登录态查询本人订单，支付状态仍由经过验签的异步通知更新。
- 模板访问统一限制为公开且已发布模板对登录用户开放，私有、草稿及下架模板仅作者或管理员可访问。搜索、详情、相关项、评论、收藏、使用、分享、举报等路径均校验；收藏列表过滤不可见模板。管理端可见列显示实际有效范围。
- 共享知识库成员列表与成员详情补齐权限；两个移除成员入口使用同一套逻辑，禁止移除创建者并同步人数。
- 用户端 Markdown 预览补充 HTML 清理，管理端模板与文章预览禁用原始 HTML。

### 图片、附件、聊天与笔记定位

- 附件发送时固定当前附件集合与文本。同名附件使用编号区分，支持结合 MIME 与扩展名识别；成功后清理本次附件，失败保留输入与附件以便重试。
- 解析附件前锁定发送状态与目标会话，避免重复发送、解析期间切换会话导致错投；预览 URL 单独管理。
- 会话历史请求增加版本与会话检查，防止切页后旧历史覆盖正在生成的内容；结束后重新读取落库消息，删除生成中会话会中断请求。
- 笔记链接中的 `noteId` 在初次进入和后续变化时均加载，并防止过期请求覆盖；保留链接参数，使图片生成的笔记打开、刷新后仍能定位。
- 新共享库无封面时使用本地备用封面，避免写入不可用外链。
- 广场分类指纹加入正文摘要，点赞、收藏、浏览不再触发重新分类；主题匹配覆盖全部公开候选，模型提炼输入最多 100 篇。

### 管理端业务完善

- 个人中心移除写死的用户资料与假保存，接入真实资料获取、保存、取消、生日清空与修改密码；改密成功后重新登录。
- 用户编辑增加会员有效期校验：设为有效会员必须存在未来到期时间；后端事务保证失败时个人资料也不被部分保存。
- 免费配额不再代表已开通会员；创建会员记录时初始化默认配额与实际知识库使用数，避免后台编辑后意外出现零配额。
- 模板返回真实公开状态、发布状态和创建时间；管理筛选使用真实状态。提交失败时弹窗与正文保留，成功后关闭，提交中禁止重复操作；未按回车的标签也会一并提交。
- 订单统计明确区分筛选总数与本页统计，避免把当前页金额误当全部收入；笔记本年份基于真实创建时间并与其他筛选组合。
- 广场管理删除没有实际后端行为的“清空数据”操作。表格图标改为有名称的原生按钮，支持键盘操作与可访问名称。

## 数据检查与清理

检查前通过 `pg_dump` 保存数据库备份，并验证可由 `pg_restore` 读取。备份与含凭据的测试状态仅留在本机审计输出目录，不加入仓库。

修正了 4 条确定不合理的业务状态：3 条已过期邀请从待处理转为过期；1 条无到期时间的免费账号会员标记设为无效。没有替换用户正文、补造交易或批量重写业务时间。审计 SQL 使用 `Asia/Shanghai`，避免 UTC 与本地无时区字段比较造成“未来时间”误判。

测试结束后按本轮账号身份、创建时间和资源归属核对范围，清理 4 个隔离账号及其笔记、团队、知识库、聊天、任务、计划、临时模板和向量。真实上传的 1 个 OSS 对象已单独删除并验证 HEAD 为 404；隔离会话已注销，相关 Redis 聊天记忆按精确键清理，没有清空 Redis 或重置自增序列。

清理后 41 项一致性检查均未发现异常，涵盖归属、引用、互动计数、成员/文件计数、邀请状态、1024 维向量、任务状态、复习周期、订单状态、会员有效期与额度、聊天摘要、团队版本/父子关系、模板评分与回收站关系。该结果属于所列规则的数据库检查，不等于对每条业务内容作人工事实核验。
